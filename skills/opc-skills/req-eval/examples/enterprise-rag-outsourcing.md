# 示例：某央企销售部 AI 知识库问答助手（A 外包需求类）

> 真实案例样本。演示 A 类（外包）评估的颗粒度与结构。新评估前可对照。

## 项目类型判定
**A 外包需求类**。信号：央企（某央企）销售部、有方案 PPT、要 PC 端 + 微信小程序、需报价。

## 一句话定性
标准企业级 RAG 知识库问答产品：三端（PC Web + 微信小程序 + 后台）+ RAG 引擎（解析/检索/溯源）+ 隐藏的 BI 模块（销售数据 AI 分析）。方案是售前宣传册风格，**非可执行 SRS**。

## 需求成熟度体检
- 🟡 方案只有功能罗列，无技术选型/数据来源/部署架构/工作量
- 🔴 自相矛盾：封面"本地知识库" vs "云端部署"，未定
- 🔴 两套账号逻辑并存：微信一键登录 vs 管理员统一账号
- 🔴 BI 模块只用 6 个标签带过，是隐形大头
- 🔴 零非功能性需求（并发/SLA/安全/合规/准确率标准）

## 工作量分解（自研 v1）
| 模块 | 人月 |
|---|---|
| AI RAG 引擎 | 2.5–3.5 |
| PC Web 用户端 | 1.5–2 |
| 后台管理 | 2.5–3 |
| 微信小程序 | 1.5–2 |
| 销售数据 BI | 2.5–3.5 |
| UI/UX | 1–1.5 |
| 测试/部署/文档/验收 | 1.5–2 |
| PM/缓冲 | 1–1.5 |
| **合计** | **14–19（中位 ~16）** |

## 报价区间（2026-06，人月×单价法）
| 档位 | 区间 |
|---|---|
| 精简二开版（MaxKB/Dify 二开） | ¥18–32 万 |
| 标准自研版（推荐） | ¥38–60 万（中位 ~48 万） |
| 国企完整版（私有化+信创+等保+品牌） | ¥75–120 万 |
持续成本：Token 按量 + 年运维 15–20%。

**自我反驳**：前提是 16 人月 × ¥3 万。若甲方接受开源二开可落到 ¥18–32 万；若要私有化+等保三级+深度 BI 可冲到 ¥75–120 万。落点由 P0 需求决定。

## 开发前必须敲定（P0）
1. 部署模式：私有化 vs SaaS
2. 大模型：商业 API vs 私有化开源模型
3. BI 数据源：对接 ERP/CRM 还是 Excel 导入
4. BI 深度：真 ML 预测还是规则+大模型解读
5. 是否信创适配 + 等保级别

## 结论
**有条件接**。前置：敲定 P0 五项 → 细化为带 WBS 的 SRS + 固定报价。置信度：中（区间稳，确切数字依赖未定项）。
