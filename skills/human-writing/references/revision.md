# 改稿规则:绝对禁词与语境判断词

## 绝对禁词(命中即改)

- 翻案腔:"不是……而是……""并非……而是……""不在于……而在于……""与其说……不如说……""表面……实际……""看似……实则……""你以为……其实……""回头才发现""说到底""答案恰恰相反""A不重要,重要的是B"
- 洞察路标:"更微妙的是""还有一层""只说对了一半""值得注意的是""需要指出的是""从某种意义上说"
- 口头黑话:"说白了""说穿了""先说结论"
- 商业黑话:赋能、抓手、闭环、沉淀、拉通、底层逻辑、顶层设计、认知跃迁、价值释放等
- 破折号和提示性冒号

## 语境判断词(结合上下文判断)

- "不只……还……"是正常递进,可用;用于翻案抬价时按翻案腔处理。
- "本质""核心"等词,在真正说明事物性质时可用。

## 改稿方法

- 修改违禁句时,先找它原本想说的事实。
- 用普通句子说出来,不寻找另一种漂亮句式替换。
- 修改后运行 check_prose.py 检查,直到禁用项清零。

## 检查脚本使用

```
python3 scripts/check_prose.py <稿件路径>
```

脚本只报警,不自动改文。警告项供作者判断,硬禁令必须清零。
