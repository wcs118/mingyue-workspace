# framework-ops — 框架运维操作手册

0号v8 三体系框架(R1-R8)的行为载体之一。涉及技能库治理、子代理调度、文档产出规范。

## 技能库治理(R7)

### 技能创建四问(吸收/自建前过)
1. 技巧对你不是显而易见的吗?
2. 会跨项目复用吗?
3. 模式普适(非项目特定)吗?
4. 别人会受益吗?

四项全过才建;一次性方案/通用实践/项目特定约定/机械可自动化的 → 不建技能。

### 两类吸收
- 方法型(流程/原则/判断)→ 提炼观察 → 晋升进 rules/(如 doc-coauthoring 六步、范围分解)
- 工具型(具体操作/参数/库用法)→ 只进技能库按需加载,不提炼规则(如 pdf/pptx 色值)

### 合集型判定
索引式合集(awesome 系列、几百技能的聚合库)= 无法逐个深读且大量重复 → 不吸收,记录为参考。
合集 ≠ 技能库,吸收标准是"可深读的方法论实体"。

### 技能生长(O2 内生长)
observations 中同一操作模式成功证据 ≥3 次且无失败 → 标 #skill-candidate → 聚类对比现有技能 → 过四问 → 生成提案 → 安全扫描+测试 → Active。与 skill-absorb.sh 外吸收互补。

## 并行子代理调度(R5)

### 可并行判定
- 可并行 = 独立领域 + 无共享状态 + 输出明确
- 不可并行 = 相关失败/需全系统上下文/探索性调试/共享状态

### 任务书五要素
聚焦 / 自包含 / 输出明确 / 完成标准可判定 / triage

### 角色化编排扩展点(O11)
同一任务 ≥3 个并行子代理需产出衔接/交接 → 升级为 planner/executor/reviewer 角色化;条件不满足不启用。

## 文档与产出规范(R8)

- 文档协作六步:①问模板/读现有文档 ②澄清 ③头脑风暴 ④策展取舍 ⑤查缺 ⑥草稿+迭代+读者测试
- 引用不复制:交接/总结类文档不复制已有产物内容,引用路径即可
- 输出塑造:下个动作前置(第一行就是可做的事);多步任务编号;收尾给一个具体动作;抑制岔题
- 去 AI 味:文本润色改最少效果最大、保留创作意图;AI 味识别——长停顿符号堆叠、过度排比、万能总结段
- 教学三阶:知识(高信任源)→技能(互动课程)→智慧(互动实践)
