# 图像七要素 & 视频双维度 方法论

## 一、图像七要素(单帧画面质量)

任何一张好图,都由七个要素决定。写提示词 / 检查成片时,逐项对照:

### 1. 主体 (Subject)
- 画面中心是什么?人物/物体/场景,必须明确单一
- 提示词写法:主体名词 + 关键特征(年龄/身份/服饰/状态)
- 常见错误:主体模糊,一图多主角,AI 不知道画谁

### 2. 构图 (Composition)
- 主体放哪?用什么构图法则
- 常用:三分法 / 居中对称 / 引导线 / 框架构图 / 对角线 / 留白
- 提示词写法:直接点名("三分法构图,主体位于右三分之一处")
- 常见错误:主体贴边、头被裁、画面失衡

### 3. 光线 (Lighting)
- 光源在哪?什么性质的光?什么时段?
- 常用:自然光(清晨/黄昏金色光)/ 逆光剪影 / 侧光塑形 / 顶光 / 霓虹 / 烛光 / 伦勃朗光
- 提示词写法:"柔和晨光从左侧45°照来,形成长阴影"
- 常见错误:无光感、光源矛盾(影子方向与光不一致)

### 4. 色彩 (Color)
- 整体色调?什么情绪?
- 常用:暖色调(橙黄,温馨)/ 冷色调(蓝青,冷静科幻)/ 低饱和(复古)/ 高饱和(活力)/ 撞色(视觉冲击)/ 单色(极简)
- 提示词写法:"低饱和莫兰迪色系,青橙对比"
- 常见错误:色彩杂乱、无主色调、皮肤色失真

### 5. 质感 (Texture)
- 表面细节是什么触感?皮肤/布料/金属/玻璃/水面/粗糙/光滑
- 提示词写法:"粗粝的水泥墙""丝绸般的光泽""湿润的雨后路面反光"
- 常见错误:画面发虚发平(塑料感)、细节缺失

### 6. 景深 (Depth of Field)
- 前后虚实关系?几层空间?
- 常用:浅景深(背景虚化,突出主体)/ 深景深(前后都清晰,大场景)/ 前后景层次
- 提示词写法:"f1.4 大光圈浅景深,背景奶油般虚化"
- 常见错误:全是实的(无层次)或虚化过度

### 7. 氛围 (Mood/Atmosphere)
- 整体情绪基调?空气感?
- 常用:雾气 / 雨丝 / 尘土飞扬 / 星空 / 烟火气 / 孤独感 / 压迫感 / 浪漫
- 提示词写法:"薄雾笼罩的清晨,带着一丝孤寂感"
- 常见错误:画面技术满分但没有情绪,看完无感

> 检查口诀:主体明确、构图稳、光线有源、色彩统一、质感真实、景深有层次、氛围有情绪。

## 二、视频双维度(动态画面质量)

视频 = 单帧(图像七要素)+ 运动。运动从两个维度控制:

### A. 时间维度 (Temporal)
画面在**时间轴**上的变化:

| 子项 | 说明 | 提示词写法 |
|------|------|-----------|
| 镜头运动 | 推/拉/摇/移/跟/升降/环绕 | "镜头缓慢推进" "环绕主体180°" |
| 节奏 | 快慢松紧,切镜频率 | "快节奏,每秒切换" "慢镜头,时间放慢" |
| 转场 | 硬切/淡入淡出/擦除/匹配剪辑 | "渐隐转场" "通过相似形状匹配剪辑" |
| 叙事时序 | 正叙/倒叙/闪回/时间流逝 | "时间流逝,从白天到夜晚" "闪回十年前" |
| 动作演化 | 主体/环境随时间如何变化 | "花瓣逐渐凋落" "云层翻涌" |

### B. 空间维度 (Spatial)
画面在**空间布局**上的呈现:

| 子项 | 说明 | 提示词写法 |
|------|------|-----------|
| 景别 | 远景/全景/中景/近景/特写 | "大远景交代环境" "面部特写" |
| 画面调度 | 主体在画面内移动路径 | "人物从画面左侧走入,向右出画" |
| 环境纵深 | 前景/中景/背景层次 | "前景虚化树枝,中景人物,背景城市" |
| 空间关系 | 主体间的相对位置/距离 | "两人相距数米,背对背" |
| 透视视角 | 平视/俯视/仰视/第一人称/航拍 | "无人机俯瞰" "低角度仰拍" |

> 视频质量 = 每帧都过七要素 + 时间维度讲清"怎么变" + 空间维度讲清"在哪变"。

## 三、实战:结构化提示词模板

### 图像模板
```
[主体] + [构图] + [光线] + [色彩] + [质感] + [景深] + [氛围]
例:一位穿红色风衣的女性站在雨夜街头,三分法构图居右,
霓虹灯光从侧面照来(青红撞色),湿润的路面倒影,浅景深虚化背景车流,
氛围孤独又带一丝赛博浪漫。
```

### 视频模板
```
[图像七要素完整描述] + [时间维度:镜头运动/节奏/转场/变化] + [空间维度:景别/调度/纵深]
例:黄昏海滩,一位老人独坐礁石,逆光剪影,暖橙色调,海面细碎反光,
浅景深虚化浪花,氛围平静苍凉。
镜头:无人机缓慢后拉,从特写拉到大远景;时间流逝,天空由橙转紫;
空间:前景浪花虚化,中景老人,背景海平线落日。
```

## 四、使用场景
- 文生图/文生视频提示词编写(Minimax H3、即梦、可灵、Midjourney 等)

- 成片质量检查(逐项打分)
- 分镜脚本设计(每镜 = 七要素 + 双维度)
