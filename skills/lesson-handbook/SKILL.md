# 课程化教学手册模板

> 来源:吸收壹镜工坊 AI 的教学法(2026-08-18 老板批准)。
> 原则:先文档后实操;老板照着点就能用;每课完成标准可自检。

## 手册结构(5 部分)

```
# <技能名> 实操教学手册

## 第一部分:环境准备
- 一次性配置步骤(做完以后每次直接开)
- 需要的前置条件/依赖

## 第二部分:N 课实操(由易到难)
### 第 1 课:<最简单任务>
- 用途:这个课能做什么
- 实操步骤:上传什么/填什么/点哪(一步步,照做即可)
- 完成标准:做到什么程度算完成(可自检)
- 要记住的点:易错点/关键参数

### 第 2 课:<进阶任务>
(同上结构)

## 第三部分:通用要点
- 常用操作(开始/停止/保存)
- 关键参数速查(Steps/CFG/Seed/分辨率/模型名)
- 资源在哪(不用重复下载的东西)

## 第四部分:学习记录表
| 日期 | 课程 | 用了什么 | 效果如何 | 问题/改进 |
|---|---|---|---|---|

## 第五部分:费用效率(如涉及付费资源)
- 单价/小时、用完即释放、省钱技巧
```

## 四件套核心(每课必备)
1. **用途** — 这课学了能干嘛(一句话,老板先看这个)
2. **实操步骤** — 上传什么/填什么/点哪(编号列表,无歧义)
3. **完成标准** — 到什么程度算完成(可自检:看到什么画面/文件生成在哪)
4. **要记住的点** — 易错点 + 关键参数(避免下次踩坑)

## 适用场景
- 给老板的技能教学(如视频生成、PPT、绘图)
- 业务流程 SOP(如电商铺货、客服配置)
- 任何"照着做就行"的操作文档
