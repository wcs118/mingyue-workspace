# AI Customer Reply — 客服应答话术

> "专业、共情、合规的客服回复,一次到位"

## When to use

- 客户咨询/售后/投诉需要拟回复话术 — "帮我回这个客户"
- 需要判断情绪与是否转人工 — "这客户在骂人,怎么接"
- 需要基于知识库/政策给出可引用来源的答复 — "按我们的退货政策怎么答"

## Workflow

1. **锁定输入**:客户消息 + 企业背景(品牌/产品/政策/语气)。背景缺失时单行声明假设后继续,不卡住。
2. **情绪与意图判断**:标注情绪(平静/焦虑/愤怒/感激)与意图(咨询/售后/投诉/营销/闲聊)。
3. **判断转人工**:出现投诉升级、舆情风险、超知识范围、情绪激烈 → 标记转人工并给出转接话术。
4. **检索依据**:有知识库时引用具体条目(id),无则基于背景拟答,**不编造事实、不虚报数字**。
5. **写回复**:共情开场(一句)→ 直接给答案 → 给下一步动作 → 收尾。语气匹配品牌(热情/克制/专业)。
6. **合规检查**:退款金额、时效、补偿等承诺一律留余地(加"以实际为准"),不代承诺无法兑现的事。
7. **输出**格式见下(脚本已固化此格式)。

## 脚本

`scripts/ai-customer-reply.py` — 调 DeepSeek API 生成话术:

```bash
export DEEPSEEK_API_KEY=...   # 读环境变量,勿硬编码
scripts/ai-customer-reply.py "客户消息" "企业背景"
```

## Output format

```
情绪: <平静|焦虑|愤怒|...>
意图: <咨询|售后|投诉|营销|...>
转人工: <是|否> — <原因,单句>
参考: <知识库id,或"无">
回复:
<可直接发送的客服话术,多轮则分行>
```

## Quality bar

- [ ] 回复可直接发送,无"待定/需要确认"的悬空
- [ ] 共情但不油腻,一句同理心足够
- [ ] 承诺留余地(时效/金额加"以实际为准")
- [ ] 情绪激烈或超范围时明确转人工
- [ ] 引用来源真实,不编造事实

## Example

**Invocation**: "客户问:快递 5 天了还没到,我要退款!按你们橙子优选的规则怎么回?"

**Produced**:
- 情绪:愤怒 | 意图:售后 | 转人工:是(物流异常+强烈退款诉求)
- 回复:"非常抱歉给您带来不好的体验,理解您着急的心情。我这边立刻为您查物流并加急处理,若确认延误会按规则补偿。麻烦提供订单号,我马上帮您跟进。"
