# 阿里云升级操作指引(2026-08-11)

> 目标:解决云盘 IOPS 受限导致的"卡死/断联"问题
> 实例:`i-bp18awjbxjvb1m7bgwwn`(杭州)| 规格 `ecs.e-c1m1.large`(2C2G)| 磁盘 40G 普通云盘(HDD)
> 推荐方案:**ESSD PL0 40G + 升配 2C4G**

---

## 一、升级前准备(5 分钟)

1. **备份确认**:数据都在云盘上,升级不会删数据。如需保险,可在控制台"云盘 → 创建快照"先打个快照(免费额度内)。
2. **通知明月**:操作前在微信说一声,我会先把 Paperclip 服务优雅停止(防止嵌入式数据库写一半),网关会自动恢复。
3. **选低峰时段**:停机变配几分钟,期间微信联系会中断,属正常现象。

## 二、步骤 1:磁盘变配(普通盘 → ESSD PL0)

**控制台路径**:云服务器 ECS → 实例 → 找到 `i-bp18awjbxjvb1m7bgwwn` → 实例详情页 → 「磁盘」页签 → 找到 `/dev/vda`(40G)→ 点「更多」→ 「变更磁盘类型」

操作细节:
1. 目标类型选 **ESSD 云盘**
2. 性能级别选 **PL0**(IOPS 上限 1 万,≈现在的 25 倍)
3. 容量保持 40G(如需扩容可一起改,建议直接 **60G**,以后不用再折腾)
4. 勾选确认,提交订单付费
5. 若提示需要停机,按提示操作(几分钟,停机期间不计费)

**费用(估)**:ESSD PL0 40G ≈ ¥20/月;60G ≈ ¥30/月(以控制台实际为准)

## 三、步骤 2:实例规格变配(2C2G → 2C4G)

**控制台路径**:云服务器 ECS → 实例 → 找到目标实例 → 「更多」→ 「实例状态」→ 「停止」(若已停机可跳过)→ 回到「更多」→ 「升降配」→ 「实例规格变配」

操作细节:
1. 目标规格选 **ecs.e-c1m2.large**(2核 4G,同系列经济型)
2. 确认变配类型与费用,提交订单
3. 变配完成后回到实例列表 → 「启动」实例

**费用(估)**:2G→4G 差价 ≈ +¥40/月(以控制台实际为准)

## 四、升级后验证(明月自动做)

1. 实例启动后,系统级服务(openclaw-gateway / paperclip)会自动拉起
2. 明月自动检查:网关健康、Paperclip 服务、磁盘 IOPS、内存
3. 验证通过后微信向老板汇报,并跑一次心跳测试确认全链路正常

## 五、省钱备选(暂不升级时的临时缓解)

- 已生效:Paperclip 服务设了低 IO 优先级(`IOSchedulingClass=idle`)
- 可再调:嵌入式 Postgres 备份间隔 60min → 180min(降低后台写盘频率)
- 但治标不治本,装大软件时仍可能触发限流,建议尽快升级
