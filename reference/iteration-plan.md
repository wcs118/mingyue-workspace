# 迭代学习计划 v1.0(2026-08-16 老板指令)

> 原则: 2000+ 技能不能一口吃成胖子。分轻重缓急,大机+小狗(小服务器)分工,不卡死任何一台。
> 目标: 别人会的我们要会,别人不会的我们也要会,比 Codex 强。

## 一、资源分工

| 机器 | 配置 | 职责 | 负载红线 |
|---|---|---|---|
| 大机(家) | 2核/7.1G/50G | 核心业务 + 明月主脑 + 守卫链/矩阵/工作流 | 负载<2,内存可用>2G |
| 小狗(学习工位) | 2核/3.4G/49G | 24h 批量学习/热榜扫描/技能试炼 | 负载<1.5,内存可用>1G |

   - 大机负责,小狗配合调研

   - 技能: agent-creator、build-mcp-server、workflow 类、superpowers 12

## 三、迭代节奏(每轮 2 天)

| 天 | 大机(明月) | 小狗 |

| D1 | P0 客服子公司: 搭 RAG demo + 微信接入 | 跑 P1 增长调研(4h)+ 技能试炼 5 个(2h) |
| D2 | P0 内容子公司: H3 出片验证 + 矩阵技能挑新 | 跑 P1 电商调研(4h)+ 试炼报告回传(2h) |

## 四、防卡死规则

1. 小狗批量任务**串行**,一次一个,超时 30min 强制 kill
2. 大机只跑**一个重活**,其他排队
3. 每次吸收技能后必须 `openclaw skills check` 验证(血的教训)
4. 每轮结束跑 phoenix-snapshot + evolution-cycle 归档经验
5. 负载超标自动降级: 小狗任务改期,保大机核心业务

## 五、验收标准

- 每轮至少 1 个子公司有**可演示产出**(demo/报告/视频)
- 新吸收技能必须进矩阵 + 组合包 + 可 lookup 命中
- 小狗回传笔记择优吸收,沉淀进技能库
