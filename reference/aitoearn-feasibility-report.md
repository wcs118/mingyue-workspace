## 三、结算规则(官方明文)

- **三种模式**:CPS(按成交额)、CPE(按互动量)、CPM(按播放量),加固定奖励/阶梯奖励/里程碑
- **千次互动换算**:点赞/转发=1次,收藏=3次,评论=5次
- **硬性要求**:30 天内不可删文,删文不予结算
- **反作弊**:无意义评论、重复评论、诱导刷评、互刷不计入有效互动(平台核查)

## 五、赚钱路径推演(三档方案)

### 方案A:轻量试水(启动成本≈0,本周可做)
- 注册 aitoearn.cn,拿 API Key
- 接**无门槛任务**(生图小程序推广,3粉即可):每篇¥1.5
- 用 pollinations 免费出图 + DeepSeek 写文案 + 一键发布小红书
- 目标:跑通链路,验证结算,日赚 ¥5-15(10篇)

### 方案B:矩阵铺量(需要 2-4 个实名小红书/抖音号)
- 用 OpenClaw 插件自动接任务 + 批量生成 + 日历排期
- 主攻:**小红书 CPE 任务**(¥20-50/千次互动)+ **抖音 CPM**(¥50/千次播放)
- 一个号每周 3-5 篇,单任务最高 ¥16-52
- 月预估:单号 ¥300-800,4 号矩阵 ¥1200-3200
- ⚠️ 风险:平台要求真实互动,刷量无效;小红书需实名、新号勿猛发

### 方案C:高价值分佣(进阶,吃内容能力)
- **短剧/小说任务(最高70%分佣)**:用 MiniMax H3 生成短剧片段 + AI 翻译出海
- 需要绑定 TikTok/YouTube 等海外号,走国际版 aitoearn.ai
- 收益上限最高,但需要稳定内容产出 + 海外账号资质

## 六、风险与坑(如实说)

| 风险 | 等级 | 应对 |
|---|---|---|
| 结算依赖平台规则(删文不结算/互动无效) | ⚠️中 | 严格按官方规则,不刷量,留 30 天不删 |

## 七、结论与建议

**结论:可行,但不值得单押。** 这是一个"锦上添花"型管道:

1. ✅ **本周先跑通方案A**(零成本):验证"接单→AI生成→发布→结算"全链路,实测真实到账金额——**先证明能收到钱**,再谈放大
2. 📈 若 A 验证 OK → 上方案B 矩阵(需老板定夺是否投入实名号资源)
3. 🎯 长期视角:它恰好是"内容子公司"的第一块试验田,但**不是全部**——我们的核心还是自建内容资产
4. 🔧 技术侧:接入 OpenClaw 插件只需一条命令(`npx -y @aitoearn/openclaw-plugin-cli`),随时可装

**给老板的一句话**:零成本试水可以马上干,投入实名号/充 MiniMax 之前先看一周实测数据。
